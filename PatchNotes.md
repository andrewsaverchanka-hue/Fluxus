# Fluxus — история изменений

Первый публичный релиз. Далее для каждой версии добавляйте раздел
`## vX.Y.Z` — скрипт публикации подставит его в описание релиза.

## v1.0.0

Первый релиз Fluxus с нативным ядром разбора логов.

### Разбор логов
- Парсеры Lima, W2 frontend и W2 low-level работают на Rust
  (модуль `fluxus_native`).
- Разбор устройств W2: выдачи, инкассации, изъятия, пополнения.
- Разбор купюр Lima: сессии, BNV-события, инкассации.
- Загрузка архивов поддержки: извлекаются только
  `devices_server.log*` и `skills-battle-frontend.log*`.
- Чтение `.gz` без полной распаковки, распаковка архивов потоково.
- Ускорение: байтовый префильтр (до 2,5× на файл) и параллельный
  разбор файлов (до 15× на пачке).

### Интерфейс
- Тёмная тема в единой палитре, безрамочное загрузочное окно.
- Страница анализатора: добавление файлов, сканирование папки,
  загрузка архива, загрузка по ссылке, drag & drop файлов и папок.
- Общая полоса прогресса для всех процессов загрузки и анализа.
- Вкладки результатов: «Статистика», «ЖЦ купюр», «BNV», «Выдачи W2»,
  «W2 Low-Level», «Health».
- «Выдачи W2» и «ЖЦ купюр»: список + карточка выбранной записи,
  поиск по купону, даты по возрастанию.
- В хронологию встроены инкассации и изъятия; колонка DS показывает
  склейку с devices_server.log.
- Статистика: KPI-карточки, блоки с копированием, копирование отчёта.
- Копирование через контекстное меню, выделение отдельных ячеек.

### Обновления
- Проверка обновлений через GitHub Releases, скачивание и установка.
- Скачивание в `downloaded_logs`, установка через временный BAT.
- Лог обновления: `%TEMP%\fluxus_update_app.log`.

### Сборка
- Nuitka (Python → C), без `.py`/`.pyc` в дистрибутиве.
- Rust-ядро собирается со `strip` и LTO.
- Артефакт называется `Fluxus.exe`.
- Проверка соответствия тега и `VERSION` при публикации.
- Очистка кэша сборки перед каждым релизом.
